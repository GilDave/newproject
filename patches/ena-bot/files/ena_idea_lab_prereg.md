# 아이디어 실험실 — 사전 등록 (결과를 보기 전에 작성: 2026-11-27)

목적: 현재 추세 전략(기준)에 덧씌우는 "노출 조절 규칙"을 넓게 시험하고, 통과하지 못하는 것은 버린다.
방식은 data/research/rules_experiment_prereg.md 와 같다. 후보마다 파라미터를 미리 고정하고 각 1회만 시험한다(튜닝 없음).

## 평가
- 18개 코인 동일가중 포트폴리오, 4시간봉, 비용 포함(수수료 0.055% + 슬리피지 2bps + 펀딩 가정). rules_experiment.py 와 같은 계산이다.
- 시작 전에 기준 전략의 숫자가 기존 결과(전체 샤프 0.67 · CAGR 16.0% · 낙폭 25.4%, 홀드아웃 0.72 · 18.3% · 25.4%)와 같은지 확인한다. 다르면 실험을 중단한다.
- 구간: 2021-01 이후 전체, 홀드아웃(2025-07~).
- 모든 신호는 결정 시점(봉 종가)에 알려진 값만 쓴다. 거시 지표는 그 시점 이전에 마감한 미국장 종가만, 롱숏비·OI 는 한 봉 늦춰 쓴다.

## 후보 (각 규칙은 노출 배수를 0.5 로 줄이기만 한다. 늘리지 않는다)
암호화폐 내부 신호
- C1 BTC 레짐: BTC 4시간봉 종가 < 200일(1200봉) 이동평균 → 모든 포지션 ×0.5
- C2 BTC 레짐(롱만): 같은 조건에서 롱 포지션만 ×0.5
- C3 변동성 급등: 코인의 30일 실현변동성이 직전 1년 분포의 90% 이상 → ×0.5
- C4 펀딩 혼잡: 8시간 펀딩률 연환산 > +30% 이면 롱 ×0.5, < −30% 이면 숏 ×0.5
- C5 롱숏비 혼잡: 롱 비율이 직전 180일 분포의 90% 이상이면 롱 ×0.5, 10% 이하면 숏 ×0.5
- C6 미결제약정 급증: 24시간 OI 변화율이 직전 180일 분포의 95% 이상 → ×0.5
- C7 프리미엄 혼잡: 프리미엄이 직전 180일 분포의 90% 이상이면 롱 ×0.5, 10% 이하면 숏 ×0.5
- C8 분할 익절: 12봉 동안 유리하게 3σ 이상 움직이면 ×0.5, 되돌려 0 이하가 되면 복귀
- C9 트레일링: 진입 후 유리한 극값에서 3σ×√6 되돌림이면 평탄, 18봉 뒤 같은 신호면 재진입
거시 지표(미국 일 단위, FRED)
- M1 S&P500 종가 < 200일 이동평균 → ×0.5
- M2 나스닥 종합 종가 < 200일 이동평균 → ×0.5
- M3 VIX 종가 > 25 → ×0.5
- M4 VIX 5거래일 상승률 > 30% → ×0.5

## 합격 기준 (후보가 13개이므로 우연히 통과하는 것이 하나쯤 나올 수 있다는 전제로 보수적으로)
- 샤프가 기준 대비 전체·홀드아웃 모두 +0.10 이상 개선
- 최대 낙폭이 기준보다 2%p 넘게 악화되지 않음
- 주 단위 부트스트랩 샤프 차이 95% 구간 하한이 전체·홀드아웃 모두 0 이상이면 "엄격 통과", 아니면 "점추정만 통과(보류, 전진검증 필요)"

## 약속
- 결과가 나빠도 그대로 보고하고, 통과하지 못한 후보는 폐기한다.
- 통과해도 본 계좌에는 연결하지 않고 그림자 계좌로 전진 검증한다.
- 결과를 본 뒤에 후보를 추가하거나 파라미터를 바꾸면 "탐색"이라고 표시하고 판정에서 제외한다.
