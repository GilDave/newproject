# 5차 — 패턴 특징을 학습기(learn2)에 넣으면 좋아지는가 — 사전 등록 (결과를 보기 전에 작성: 2026-11-27)

가설: 쌍바닥·쌍봉 등 차트 패턴의 발생 여부를 입력 특징으로 추가하면 ENA 봇의 v2 학습기(18코인 풀링 로지스틱 회귀, 목표 = "추세 방향이 이후 24시간 동안 맞을 확률")의
표본 외 예측(워크포워드)이 좋아진다. 개별 패턴 단독으로는 비용을 넘는 초과 수익이 없었지만(24건+24건 시험), 다른 특징과 결합하면 달라질 수 있는지 본다.

## 방법 (learn2 의 데이터셋·검증을 그대로 쓴다. 학습기는 바꾸지 않는다)
- 기준 모델: 기존 32개 특징(`featx.NAMES`)으로 `learn2.walk_forward`.
- 패턴 모델: 기존 특징 + 패턴 특징 14개. 같은 행·같은 폴드·같은 정규화.
- 패턴 특징(모두 마감된 4시간봉 정보만 사용, 감지기는 ena_pattern_study2.events_for 와 같은 정의, 미래 누수 없음을 테스트로 확인):
  - 12개 패턴(쌍바닥·쌍봉·역헤드앤숄더·헤드앤숄더·삼각 상/하·쐐기 상/하·깃발 상/하·박스권 상/하)별: 최근 6봉(24시간) 안에 확정 이벤트가 있었으면 1, 없으면 0.
    값에는 추세 방향 d 와 패턴의 통상 방향(롱형 +1, 숏형 −1)을 곱한다 → 패턴의 통상 방향이 현재 추세 방향과 같으면 +1, 반대면 −1.
  - 합산 2개: 위 12개의 방향 부호 합을 최근 6봉·18봉 창에서 각각(역시 d 를 곱함).
- 대조(음성 대조군): 패턴 특징 열을 행 단위로 무작위로 섞어 같은 모델을 한 번 더 학습한다(시드 고정). 이 ΔAUC 는 0 근처여야 하며, 아니면 검증 틀에 문제가 있는 것이다.

## 판정 기준 (모두 만족해야 "패턴 특징이 유효")
1. 표본 외 전체 풀링 AUC 차이(패턴 모델 − 기준 모델) ≥ +0.003
2. 같은 행에 대한 주 단위 블록 부트스트랩(500회) 차이의 95% 구간 하한 > 0
3. 테스트 연도(폴드) 중 60% 이상에서 AUC 차이가 양수
4. 음성 대조군 ΔAUC 의 절댓값이 실제 ΔAUC 보다 작을 것

## 약속
- 결과가 나빠도 그대로 보고한다. 통과하지 못하면 패턴 특징은 학습기에 넣지 않는다.
- 통과해도 본 계좌에는 연결하지 않고, 그림자 계좌(ML 게이트)에 반영해 전진검증한 뒤에 판단한다.
- 결과를 본 뒤 특징 정의·창·임계값을 바꾸면 "탐색"으로 표시하고 판정에서 제외한다.
