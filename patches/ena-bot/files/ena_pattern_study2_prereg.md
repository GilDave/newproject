# 차트 패턴 사건 연구 2차 — 사전 등록 (결과를 보기 전에 작성: 2026-11-27)

1차(쌍바닥·쌍봉, 1시간봉, ena_pattern_study_prereg.md)는 둘 다 근거 없음으로 폐기했다. 2차는 같은 방식으로 나머지 패턴과 다른 주기를 시험한다.
데이터·비용·초과 수익 계산·부트스트랩은 1차와 같다(18코인, 왕복 비용 0.15%, 같은 코인 기준 수익 제외, 주 단위 부트스트랩).

## 패턴 정의 (각 1회만 시험, 파라미터 튜닝 없음). 모두 우측 4봉이 지난 확정 피벗만 쓰고, 돌파 봉 종가에 진입한다.
- P1 역헤드앤숄더(롱) / P2 헤드앤숄더(숏): 확정 저점(고점) 3개 중 가운데가 양쪽 어깨보다 1.5×ATR 이상 깊고(높고), 어깨 차이 ≤ 1.0×ATR, 각 구간 ≥ 5봉, 전체 ≤ 150봉.
  목선 = 어깨와 머리 사이 두 고점(저점)을 잇는 직선. 확정 후 60봉 안에 종가가 목선을 처음 넘으면(이탈하면) 신호. 머리를 0.5×ATR 넘어서면 무효.
- P3 삼각 수렴 상향 돌파(롱) / P4 하향 이탈(숏): 최근 확정 고점 2개를 잇는 저항선 기울기 ≤ 0, 확정 저점 2개를 잇는 지지선 기울기 ≥ 0, 폭이 줄어드는 형태(시작 폭 ≥ 현재 폭×1.6, 현재 폭 ≥ 1.5×ATR), 마지막 피벗 확정 후 60봉 이내, 종가가 저항선(지지선)을 처음 벗어나면 신호.
- P5 하락 쐐기 상향 돌파(롱) / P6 상승 쐐기 하향 이탈(숏): 저항·지지선 모두 같은 방향(하락 또는 상승, 기울기 크기 ≥ 0.03×ATR/봉)이며 수렴, 나머지는 삼각과 같다.
- P7 상승 깃발(롱) / P8 하락 깃발(숏): 직전 12봉 안에 4×ATR 이상의 충격 파동이 있고, 충격 고점(저점) 이후 8~40봉 동안 되돌림이 충격의 50% 이하, 종가가 충격 고점(저점)을 처음 넘으면 신호.
- P9 박스권 상향 돌파(롱) / P10 하향 이탈(숏): 직전 48봉의 고저 폭이 5×ATR 이하이며 종가가 직전 48봉 고점(저점)을 처음 넘으면 신호.
- 같은 패턴 신호는 24봉 안에 다시 발동하지 않는다.
- 1차의 쌍바닥(P0W)·쌍봉(P0M)도 4시간봉에서 한 번 더 시험한다.

## 주기·평가
- 1시간봉과 4시간봉(1시간봉을 UTC 정렬로 묶음). 1차 판정은 주기마다 "24시간 뒤" 하나로 고정한다(1시간봉 24봉, 4시간봉 6봉). 나머지 선행 구간은 참고용이다.

## 합격 기준 (시험 22건: 10패턴×2주기 + 쌍바닥·쌍봉 4시간봉 2건. 보정을 엄격히)
- 이벤트 ≥ 100개
- 24시간 비용 후 초과 수익의 부트스트랩(5,000회) 신뢰구간 **하한(0.05/22 = 0.227 분위)이 0 위**
- 2024-01 이전·이후 두 구간 평균 초과 수익이 모두 양수

## 약속
- 결과가 나빠도 그대로 보고한다. 통과하지 못하면 폐기한다.
- 통과해도 본 계좌에는 연결하지 않고 전진검증(그림자)만 한다.
- 결과를 본 뒤 정의를 바꾸거나 패턴을 더하면 "탐색"으로 표시하고 판정에서 제외한다.
- 반대로 거래하는 방향(역방향)의 수익은 참고(탐색)로만 보여 주고 판정에 쓰지 않는다.
